# WDIDo



A WDIDo egy olyan webalkalmazás, amely a szakdolgozati témaválasztásban elakadt diákok számára nyújt segítséget. Elsődleges célja, hogy inspirációt és segítséget nyújtson szoftverfejlesztő és -tesztelő tanulók számára a korábbi évfolyamok sikeres projektjeinek bemutatásával és segéd eszközök biztosításával.



A 2026/2027-es tanév végére olyan projektet kellett megvalósítanunk, amely egy valós problémára kínál megoldást. Saját tapasztalataink alapján a megfelelő szakdolgozati ötlet megtalálása komoly kihívást jelenthet. Ezért egy olyan alkalmazás fejlesztése mellett döntöttünk, amely megkönnyíti a jövőbeli diákok témaválasztását, és új ötletekkel segíti őket a tervezési folyamat során.
